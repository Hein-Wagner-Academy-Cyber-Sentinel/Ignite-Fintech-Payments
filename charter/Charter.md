Project Charter — Ignite Fintech Payments
Purpose
The purpose of this project is to design, build, secure, and demonstrate a simulated cloud-based payments platform for Ignite Fintech Payments. The project focuses on protecting customer information, maintaining transaction integrity, ensuring service availability, and supporting secure business growth. The platform will be developed and tested using Academy-controlled lab environments and simulated infrastructure.

Business Background
Ignite Fintech Payments is a fictional South African digital-only payments startup that provides payment processing services for merchants and online businesses. As transaction volumes increase, the business faces growing security risks related to data protection, platform availability, transaction integrity, and rapid deployment of new features.

The project aims to demonstrate how security can be integrated into the design and operation of a modern fintech platform while supporting regulatory compliance and business growth.

Objectives
Identify and document critical business assets.
Develop and maintain a threat model throughout the project.
Design a secure platform architecture.
Implement appropriate security controls.
Demonstrate secure deployment practices.
Assess risks relating to availability, transaction integrity, and rapid growth.
Document compliance considerations for POPIA and PCI-DSS.
Produce evidence showing that security controls are functioning as intended.
Scope
The project includes:

Simulated customer personal information.
Simulated merchant personal information.
Simulated payment and transaction data.
Simulated transaction processing systems.
Simulated API gateway infrastructure.
Authentication and access control systems.
Transaction databases and ledger systems.
Simulated cloud-hosted services.
POPIA compliance considerations.
PCI-DSS compliance considerations.
Risks associated with rapid platform growth.
Security monitoring, testing, and documentation.

Success Criteria
A completed business profile, charter, and POPIA assessment are stored in the repository.
A threat model identifying risks relating to availability, transaction integrity, and rapid deployment is completed and maintained.
Security scanning tools produce documented results that are stored in the repository.
A planted test secret causes a security scan to generate a finding.
Infrastructure definitions and security controls can be deployed in the project lab environment.
Required project artefacts are version controlled in GitHub and reviewed through the team workflow.
Project documentation demonstrates consideration of POPIA and PCI-DSS requirements.
All required phase deliverables are completed and submitted on time.
Assumptions
All infrastructure used during the project is simulated or Academy-controlled.
No real customer information will be processed.
No real payment card data will be processed.
No funded cloud subscriptions are required.
Team members have access to the required project tools and repository.
Security controls can be demonstrated using a lab environment.
Out of Scope
The project does not include:

Real customer data.
Real payment card data.
Production payment processing.
Production cloud environments.
Funded or commercial cloud accounts.
Infrastructure not controlled by the Academy.
Live financial transactions.
Physical security controls.
Financial auditing activities.
Third-party systems not managed by Ignite Fintech Payments.

Working Protocol
Work is assigned according to current project roles.
Changes are committed to feature branches before being merged.
The Assurance Lead reviews work before it is merged into the main branch.
Reviews are recorded through GitHub Pull Requests and review comments.
The team communicates using WhatsApp and other agreed communication channels.
Any decisions made outside the repository are documented in the repository to maintain an auditable project record.
Team members meet regularly to review progress and plan upcoming work.
Roles rotate during project phases to ensure equal participation, knowledge sharing, and skill development.
