# Phase 1 reflection — Student B

_What did I do? What did I find hard? What would I do differently? What do I understand now that I did not before?_


What I did?
During Phase 1, I worked on the project repository, created and updated documentation, and learned how to use GitHub and Linux through WSL in a practical project setting. I also spent a lot of time working with Git commands, managing files, and contributing to the project alongside my teammate. This phase gave me the opportunity to apply some of the things I had previously learned while studying and see how they fit into a real project.

What I found hard?
One of the challenges I faced during during this Phase was learning how to use Git and GitHub properly. I knew what they were, but actually using commands like git add, git commit, and git push took some getting used to. There were definitely a few moments where I got stuck or had to figure out what went wrong, but that was all part of the learning process. The more I practiced, the easier it became to work with the command line and manage changes in the repository.

What would I do differently?
If I were to start Phase 1 again, I would spend more time getting comfortable with Git before jumping into the project tasks. Looking back, I think this would have saved me some time and helped me work more efficiently. I would also try to plan my tasks a bit better from the beginning so that I could keep track of everything more easily.

What do I understand now that I did not before?
Before this phase, I had heard people talk about Git and GitHub, but I never really understood how they worked or why they were so important. Most of my experience had focused on certifications and studying concepts rather than using tools like these in practice. Through this project, I learned how Git and GitHub are used to manage files, track changes, and collaborate on a project. I also gained experience working in Linux through WSL and became more comfortable using the command line. This phase showed me the difference between learning about a tool and actually using it to complete real work.
